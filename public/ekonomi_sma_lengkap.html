Siap GitHub Pages

File HTML tunggal ini mandiri dan bisa dijalankan langsung di HP siswa tanpa server.

🚀 Panduan Deploy GitHub Pages (1 Menit)

  1. Buat repository baru di github.com/new dengan nama misalnya ekonomi-sma (Public).
  2. Upload file ini dan pastikan diberi nama index.html, lalu klik Commit changes.
  3. Buka Settings → Pages, pada Branch pilih main dan folder /(root), lalu klik Save.
  4. Dalam 1 menit, web aktif di https://username.github.io/ekonomi-sma/ siap dibagikan ke siswa di WhatsApp!
