🚀 Panduan Guru: Upload ke GitHub Pages

Cara Agar Siswa Dapat Mengakses File Ini di HP melalui GitHub

File HTML ini bersifat Single-File Mandiri (seluruh diagram Circular Flow 3 & 4 Sektor, CSS, simulator 5 sistem ekonomi, 50 soal PG, dan 20 soal esai sudah menyatu di dalamnya) sehingga sangat ringan dibuka di HP siswa:

  1. Buat Repository Baru di GitHub: Login ke GitHub, klik New Repository, beri nama misalnya ekonomi-bab2-sistem-ekonomi, pilih Public, lalu klik Create repository.
  2. Upload File HTML Ini: Klik Add file → Upload files. Unggah file ini dan ubah namanya menjadi index.html (atau gunakan nama aslinya), lalu klik Commit changes.
  3. Aktifkan GitHub Pages: Buka menu Settings → Pages, pada bagian Branch pilih main dan folder /(root), lalu klik Save.
  4. Bagikan Link ke HP Siswa: Dalam 1 menit, link aktif https://username.github.io/ekonomi-bab2-sistem-ekonomi/ siap dikirimkan ke grup WhatsApp kelas!
