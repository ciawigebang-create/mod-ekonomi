Bab 1: Kelangkaan & Pengalokasian Sumber Daya

Pelajari secara tuntas konsep kelangkaan sumber daya ekonomi, perhitungan biaya langsung & biaya peluang (opportunity cost), kebutuhan vs keinginan, faktor penentu kebutuhan, klasifikasi & nilai guna benda pemuas kebutuhan (form, place, time, ownership utility), hingga pengalokasian SDM, SDA, dan Sumber Daya Modal. Dilengkapi Kalkulator Biaya Peluang Interaktif, 50 Soal Pilihan Ganda, dan 20 Soal Esai beserta pembahasannya!

5 Tujuan Pembelajaran Utama Bab Ini

Tujuan 1

Membedakan dan mengidentifikasikan kebutuhan dan benda pemuas kebutuhan.

Tujuan 2

Memahami faktor-faktor yang memengaruhi kebutuhan dan benda pemuas kebutuhan.

Tujuan 3

Memahami jenis serta nilai guna (utility) benda-benda pemuas kebutuhan.

Tujuan 4

Memahami kelangkaan sumber daya ekonomi serta kaitannya dengan kebutuhan tak terbatas.

Tujuan 5

Melakukan perhitungan biaya peluang (opportunity cost) dan pengalokasian sumber daya.

🚀 Panduan Guru: Upload ke GitHub Pages

Cara Agar Siswa Dapat Mengakses File Ini di HP melalui GitHub

File HTML ini bersifat Single-File Mandiri (seluruh ilustrasi SVG, CSS, kalkulator, 50 soal PG, dan 20 soal esai sudah menyatu di dalamnya) sehingga sangat ringan dibuka di HP siswa:

  1. Buat Repository Baru di GitHub: Login ke GitHub, klik New Repository, beri nama misalnya ekonomi-kelangkaan, pilih Public, lalu klik Create repository.
  2. Upload File HTML Ini: Klik Add file → Upload files. Unggah file ini dan ubah namanya menjadi index.html (atau gunakan nama aslinya), lalu klik Commit changes.
  3. Aktifkan GitHub Pages: Buka menu Settings → Pages, pada bagian Branch pilih main dan folder /(root), lalu klik Save.
  4. Bagikan Link ke HP Siswa: Dalam 1 menit, link aktif https://username.github.io/ekonomi-kelangkaan/ siap dikirimkan ke grup WhatsApp kelas!
